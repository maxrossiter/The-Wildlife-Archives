THE WILDLIFE ARCHIVES — iPHONE WEB APP

To install: Upload ALL files in this folder to an HTTPS static website host (e.g. Netlify Drop, Cloudflare Pages, or GitHub Pages). Open the hosted URL in iPhone Safari, tap Share > Add to Home Screen. Open the installed app at least once while online to cache it for offline use.

Data and photographs are saved locally on that iPhone in IndexedDB. They do NOT sync across devices. Regularly use Settings > Export complete backup and save the JSON to iCloud Drive or Files. Import restores the entire archive, replacing the current archive. Never rely on browser storage as your only copy.

The South Africa checklist is an extensive starter selection, not a complete taxonomic inventory. Add additional species through the New safari sighting form.
